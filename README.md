Este programa implementa diferentes estructuras de datos utilizando C++.
Incluye pilas, colas, listas ligadas, grids, árboles binarios y árboles AVL.
El AVLTree mantiene el árbol balanceado automáticamente después de cada inserción.
Para balancearse utiliza rotaciones simples y dobles según su factor de balance.
El programa compara un BST normal contra un AVL insertando los valores del 1 al 15.
También incluye pruebas y recorridos In-Orden para comprobar el funcionamiento de las estructuras.
