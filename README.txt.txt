Este programa implementa una lista ligada en C++ para almacenar y administrar datos de forma dinámica.
Permite agregar elementos, consultar posiciones, conocer el tamaño de la lista y mostrar su contenido.
Incluye algoritmos de ordenamiento como Selection Sort e Insertion Sort para organizar los datos de menor a mayor.
La memoria utilizada por los nodos se administra correctamente y se libera al finalizar la ejecución del programa.
También cuenta con una clase ConsoleUI encargada de mejorar y organizar la presentación de información en la consola.
En general, el programa aplica conceptos de estructuras de datos, programación orientada a objetos, memoria dinámica y separación de responsabilidades.
